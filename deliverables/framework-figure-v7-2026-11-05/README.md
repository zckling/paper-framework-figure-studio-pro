## 对本轮意见的落实

1. 支持集同时供给特征缓存和提示优化，监督预算是同一组 2K 张图像。提示拟合区包含图像/提示输入、固定文本参与的原生 CLIP logits、标签进入的 CE，以及只更新提示的反馈环；P* 表示优化后的状态。
2. 明确 CLIP ViT-L/14 的 blocks 1–12 与 blocks 1–24 + prompts：两路使用相同预训练权重、独立前向，输出空间分别为 1024 与 768 维。
3. 原型细节改为类内 softmax、加权聚合、等权混合与 L2 归一化，删除无标签几何框。m_c(q) 在混合前不再次归一化。
4. 提示细节区分已学参数 P_s* 与经过阶段计算的提示状态，画出保留 CLS/image、叉号丢弃旧状态、插入下一组提示以及最终 CLS 投影。
5. 主图用 (a)/(b)/(c) 文字锚点对应总览与细节，避免将细节指引画成数据流；用局部缓存/提示状态端口缩短连接。
6. 将推理相似度命名为 Cosine similarity difference；最终只用一个 Probability average 模块表达概率平均。原型概率统一写 p_p(q)，融合中的图像输入简写等价于 p_p(q(x))。
7. CE 使用原生冻结尺度 S=exp(logit_scale)，推理固定为15；四组提示共同优化，推理不更新，不使用 query 标签。
8. 蓝圆/绿方分别保持 real/fake，橙色用于提示，细节背景改为中性浅灰，图例集中为一行。

## 证据和执行边界

方法证据来自交接材料的原文摘录、连线规范和三份提示代码。三份代码仅覆盖提示分支；原型计算和融合前 15/S 转换的依据是方法正文，未伪称来自这三份代码的完整实现。

当前 v7 run 从用户对已有 v6 的明确修改请求开始，导入原有方法证据与 v6 偏好图，未把 v6 伪登记成此 run 的 S2 生图。当前“使用 skill 来画”的请求作为本轮指定修改与生成的授权，未重新要求 bootstrap 确认。早先用户明确要求可编辑 Visio，故矢量伴随稿作为单独交付保存；正式栅格候选仍由 image_gen 生成。
